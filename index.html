About PagePilot

PagePilot is a locally operated tool that helps an authorized Facebook Page administrator prepare, schedule and publish Page content, review comments and prepare replies.

The application runs on the administrator's own computer. Public access to this website is provided only for legal information and data-deletion instructions.
